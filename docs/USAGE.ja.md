# 使い方

[English](USAGE.md) | [简体中文](USAGE.zh-CN.md) | [繁體中文](USAGE.zh-TW.md)

## キー

`A+B` は「`A` を押しながら `B`」です。表は既定値で、ホットキーはすべて設定画面で変えられます。

### Item Scroller: 移動（コンテナの画面で）

| キー | 動作 |
|---|---|
| スタックの上でホイール | 1 個ずつ反対側へ移す（上下で向きが変わる） |
| `Shift` + ホイール | スタックごと移す |
| `Alt` + ホイール | 同じアイテムを全部移す |
| `Alt+Shift` + ホイール | すべてのアイテムを移す |
| `Shift` + 左ドラッグ | なぞったスタックを移す |
| `Shift` + 右ドラッグ | なぞったスタックを 1 個残して移す |
| `Ctrl` + 左ドラッグ | なぞったスタックから 1 個ずつ移す |
| `Alt` + 左ドラッグ | なぞった物と同じアイテムを全部移す |
| `Alt+Shift` + 左クリック | すべてのアイテムを反対側へ移す |
| `Q` + 左ドラッグ | なぞったスタックから 1 個ずつ捨てる |
| `Shift+Q` + 左ドラッグ | なぞったスタックを丸ごと捨てる |
| `Shift+Q` + 右ドラッグ | 1 個残して捨てる |
| `W` / `S` + 左クリック | 1 個を画面の上 / 下の側へ移す |
| `Shift+W` / `Shift+S` + 左クリック | スタックを上 / 下へ移す |
| `Alt+W` / `Alt+S` + 左クリック | 同じアイテムを全部 上 / 下へ移す |
| `W` / `S` + 右クリック | 1 個残して 上 / 下へ移す |
| スタックの上で `Ctrl+Shift+Q` | 同じアイテムをすべて捨てる |
| カーソルに持って `Shift` + 枠の外を左クリック | 持っている物と同じ物を全部捨てる |
| カーソルに持って `Shift` + 空きマスをクリック | 同じ物を置く |

### Item Scroller: クラフト（作業台）

| キー | 動作 |
|---|---|
| `A` を押しながら結果の枠で中クリック | グリッドのレシピを記憶する |
| `A` を押している間 | 記憶したレシピの一覧を出す |
| 一覧でレシピをクリック | 選んで材料をマスに入れる |
| `Ctrl+C` | 選んだレシピで作れるだけ 1 回クラフトする |
| `Ctrl+Alt+C` を押している間 | 大量にクラフトし、できた物を投げ捨てる |
| `Ctrl+M` | できた物をインベントリ（または反対側）へ移す |
| `Ctrl+T` | できた物を地面に投げる |
| 結果の枠を右クリック | 1 スタック分クラフトする |
| 結果の枠でホイール | クラフトして移す |

### Inventory Profiles Next: 並べ替え・移動

| キー | 動作 |
|---|---|
| `R` | マウスの下のインベントリやコンテナを並べる（既定はホットバーを除く） |
| `Alt+R` | ホットバーも含めて並べる |
| 並べ替えボタン（右上） | 通常・列・行の形で並べる |
| 並べ替えボタンの上でホイール | 並び順の方式を変える |
| 全部移動のボタン / `R+T` | 同種を反対側へ移す |
| `Shift` + 全部移動 | 全部を移す |
| `Ctrl` + 全部移動 | マウスの下の種類だけ移す |
| `CapsLock` + 全部移動 | 反対側のスタックを補充するだけ |
| `R+M` | 同種を捨てる（`Shift` で全部） |

### Inventory Profiles Next: ロック・自動補充・プロファイル

| キー | 動作 |
|---|---|
| `Alt` + スロットを左クリック | スロットのロック / 解除 |
| `Alt` を押しながら道具を使う | 道具の補充を一時的に止める |
| `Ctrl` + スロットを左クリック（インベントリ） | そのスロットの自動補充の オン / オフ |
| `Ctrl+R`（HUD） | 今のホットバーの枠の自動補充の オン / オフ |
| `R+P`（インベントリ） | 今の装備をプロファイルに保存する |
| `R+1`〜`R+0`（HUD） | その番号のプロファイルを適用する |
| `R+Z` / `R+X`（HUD） | 次 / 前のプロファイル |
| `R+H`（HUD） | 保存した持ち物の並びに戻す |
| `R+Y` | 規則・プロファイル・ロックを読み直す |

### Inventory Profiles Next: 作業系の画面と取引

| キー | 動作 |
|---|---|
| 連続クラフトのチェック | 材料が減ると同じ配置に補充する（作業台・石切台） |
| Fast Rename のチェック（金床） | 連続で名前を付ける |
| 取引の上で `B` / `L` | 全体 / この村人のお気に入りにする |
| `T` | 全体のお気に入りの取引を実行する |
| `Shift+T` | この村人のお気に入りの取引を実行する |

### クラフトツール（作業台のみ）

グリッドの左に 3 つのボタンが出ます。**ホットキーは既定で未割当**なので、設定画面で割り当ててください。

| 操作 | 動作 |
|---|---|
| 回す / `Shift` + 回す | 外周を時計回り / 反時計回りに 1 つずらす |
| ならす | 同じ種類のマスで数を等分する |
| `Shift` + ならす | 1 種類だけのとき全マスに等分する |
| クリア | 中身をインベントリへ戻す |
| `Shift` + クリア | 入りきらない分も捨てて空にする |
| 圧縮 / すべて圧縮（ホットキー） | マウスの下の物の 9 個（または 4 個）→ ブロックのレシピを並べる |
| 展開 / すべて展開（ホットキー） | ブロック 1 個をばらすレシピを並べる |

### ホットバーのお気に入り

コンテナの画面の左上（JEI があるときは JEI の欄の下）に欄が出ます。JEI は不要です。

| 操作 | 動作 |
|---|---|
| `+` ボタン、またはホットキー `saveHotbar`（既定は未割当） | 今のホットバーを行として保存する |
| 行を左クリック（クリエイティブ） | 持っていなくても登録した内容をホットバーに出す |
| 行を左クリック（サバイバル） | インベントリにある同じ物だけ入れ替える |
| 行にマウスを乗せて `A` | その行を消す |

## 設定画面

`R+C` または `/invutils gui [itemscroller|ipnext|craftingtools|favorites]` で開きます。上に Mod のタブ、左に区画、右に項目が並びます。前回のタブで開き、閉じると保存されます。

- 検索欄・見出しの索引・項目ごとの Reset
- 数の項目: スライダー、または `T` で入力欄に切り替え
- ホットキー: ボタンを押してキーを押し、全部離すと割り当たる。`Esc` で割り当てなし。左のアイコンで詳細設定（右クリックで既定に戻す）
- 色: 色見本と `#AARRGGBB` の入力欄

## コマンド

| コマンド | 説明 |
|---|---|
| `/invutils gui [タブ]` | 設定画面を開く |
| `/invutils config list [区画]` | 区画の一覧、または区画の項目と値を出す |
| `/invutils config get <区画> <名前>` | 項目を表示する |
| `/invutils config set <区画> <名前> <値>` | 項目を変える（ホットキーは `LEFT_CONTROL,C` の形） |
| `/invutils config reset <区画> <名前>` | 項目を既定に戻す |
| `/invutils save` / `reload` | 設定ファイルを書き出す / 読み直す |

## 設定ファイル

`mods/InventoryUtils/config/` にあります。

| ファイル | 内容 |
|---|---|
| `itemscroller.json` | Item Scroller の設定 |
| `recipes_<ワールド名>.json` | 記憶したレシピ |
| `inventoryprofilesnext/inventoryprofiles.json` | Inventory Profiles Next の設定 |
| `inventoryprofilesnext/rules-v2.*.txt` | 並べ替えの規則 |
| `inventoryprofilesnext/<ワールド名>/lockSlots.txt` | スロットのロック |
| `inventoryprofilesnext/<ワールド名>/profiles-V2.txt` | プロファイル |
| `inventoryprofilesnext/villager-trading-config-v2.json` | 取引のお気に入り |
| `craftingtools.json` | クラフトツールの設定（`mode`: `BUTTONS_AND_KEYS` / `KEYS_ONLY` / `DISABLED`、`showButtons`、ホットキー） |
| `hotbarfavorites.json` | ホットバーのお気に入りの設定 |
| `hotbar-favorites.json` | 保存したホットバー |
