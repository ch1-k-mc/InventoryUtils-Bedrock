## Item Scroller

- 用滚轮移动：1 个、整堆、所有同种、全部
- 拖动移动或丢弃（整堆、保留 1 个、逐个、同种）
- 用 `W` / `S` 移向界面上方 / 下方
- 丢弃所有同种物品；用 `Shift` 放置
- 按世界记住配方并从列表合成
- 批量合成，移动或丢出成品，从结果槽合成一组
- 创造模式下也可用（`enableInCreative`，默认开启；为基岩版新增）

## Inventory Profiles Next

- **整理**：普通、按列、按行，可选择排序方式和规则文件
- **移动**：全部、仅同种、鼠标所指种类、仅补充；丢弃同种物品
- **槽位锁定**：整理和移动时跳过，在界面和快捷栏上显示锁标记
- **自动补充**：替换用完的物品堆和快损坏的工具，可按槽位开关
- **配置档**：保存并切换装备和快捷栏布局
- **连续合成**：工作台、切石机
- **铁砧**：Fast Rename
- **村民交易**：全局 / 单个村民的收藏，按键执行

## 合成工具 类功能

根据公开的功能说明独立实现。仅限工作台。

- 旋转、均分、铺开、清空、强制清空
- 使用 9 个 / 4 个物品的配方压缩和解压
- 网格左侧的按钮；模式可选 `BUTTONS_AND_KEYS`、`KEYS_ONLY`、`DISABLED`

## 快捷栏收藏

- 保存整条快捷栏，并从容器界面的面板调用。无需 JEI
- 创造模式下即使没有这些物品也会提供
- 生存模式下只换入物品栏中已有的相同物品
- 带数据的物品（如装有物品的箱子）**仅在本地世界**可连同 NBT 恢复，外部服务器不可

## 设置界面

一个界面（`R+C` 或 `/invutils gui`）包含 Item Scroller、Inventory Profiles Next、合成工具 类功能和快捷栏收藏的标签页。提供搜索、章节索引、滑块、快捷键录入和各选项的重置。

## 与 Java 版的差异

- 重复的功能已合并：整理和村民交易使用 Inventory Profiles Next，滚轮、拖动移动和合成辅助使用 Item Scroller。
- 只用一个按键（`R+C`）打开所有设置。
- Inventory Profiles Next 中带切换键的布尔选项在此仅为布尔值。
- 颜色通过色块和 `#AARRGGBB` 输入框编辑，没有取色器。

## 已知问题

- 仅限客户端。需使用键盘、鼠标和 PC 经典 UI。
- 不在创造模式物品列表中的自定义 NBT 物品，除非已持有，否则无法在外部服务器上恢复。
- 快速拖动鼠标时可能漏掉槽位。
- 自动补充的通知没有声音。
- 并非所有功能都在外部服务器上测试过，Realms 尚未测试。
