# 功能

## Item Scroller

- 用滾輪移動：1 個、整堆、所有同種、全部
- 拖曳移動或丟棄（整堆、保留 1 個、逐個、同種）
- 用 `W` / `S` 移向畫面上方 / 下方
- 丟棄所有同種物品；用 `Shift` 放置
- 依世界記住配方並從清單合成
- 大量合成，移動或丟出成品，從結果欄合成一組
- 創造模式下也可使用（`enableInCreative`，預設開啟；為基岩版新增）

## Inventory Profiles Next

- **整理**：一般、依欄、依列，可選擇排序方式與規則檔
- **移動**：全部、僅同種、滑鼠所指種類、僅補充；丟棄同種物品
- **欄位鎖定**：整理與移動時略過，在畫面與快捷列上顯示鎖定標記
- **自動補充**：替換用完的物品堆與快損壞的工具，可依欄位開關
- **設定檔**：儲存並切換裝備與快捷列配置
- **連續合成**：工作台、切石機
- **鐵砧**：Fast Rename
- **村民交易**：全域 / 單一村民的收藏，以按鍵執行

## 合成工具

依公開的功能說明獨立實作。僅限工作台。

- 旋轉、均分、鋪開、清空、強制清空
- 使用 9 個 / 4 個物品的配方壓縮與解壓
- 網格左側的按鈕；模式可選 `BUTTONS_AND_KEYS`、`KEYS_ONLY`、`DISABLED`

## 快捷列收藏

- 儲存整條快捷列，並從容器畫面的面板叫用。不需要 JEI
- 創造模式下即使沒有這些物品也會提供
- 生存模式下只換入物品欄中已有的相同物品
- 帶資料的物品（如裝有物品的箱子）**僅在本機世界**可連同 NBT 還原，外部伺服器不可

## 設定畫面

一個畫面（`R+C` 或 `/invutils gui`）包含 Item Scroller、Inventory Profiles Next、合成工具與快捷列收藏的分頁。提供搜尋、章節索引、滑桿、快捷鍵擷取與各選項的重設。

## 與 Java 版的差異

- 重複的功能已合併：整理與村民交易使用 Inventory Profiles Next，滾輪、拖曳移動與合成輔助使用 Item Scroller。
- 只用一個按鍵（`R+C`）開啟所有設定。
- Inventory Profiles Next 中帶切換鍵的布林選項在此僅為布林值。
- 顏色透過色塊與 `#AARRGGBB` 輸入框編輯，沒有取色器。

## 已知問題

- 僅限用戶端。需使用鍵盤、滑鼠與 PC 經典 UI。
- 不在創造模式物品清單中的自訂 NBT 物品，除非已持有，否則無法在外部伺服器上還原。
- 快速拖曳滑鼠時可能漏掉欄位。
- 自動補充的通知沒有音效。
- 並非所有功能都在外部伺服器上測試過，Realms 尚未測試。
