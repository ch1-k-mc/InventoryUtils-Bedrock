## 按键

`A+B` 表示按住 `A` 再按 `B`。下表为默认值，所有快捷键都可在设置界面中更改。

### Item Scroller：移动（在容器界面中）

| 按键 | 功能 |
|---|---|
| 在物品堆上滚动滚轮 | 逐个移到另一侧（上下决定方向） |
| `Shift` + 滚轮 | 移动整堆 |
| `Alt` + 滚轮 | 移动所有同种物品 |
| `Alt+Shift` + 滚轮 | 移动所有物品 |
| `Shift` + 左键拖动 | 移动拖过的物品堆 |
| `Shift` + 右键拖动 | 移动拖过的物品堆，保留 1 个 |
| `Ctrl` + 左键拖动 | 从拖过的每堆移动 1 个 |
| `Alt` + 左键拖动 | 移动与拖过物品同种的全部物品 |
| `Alt+Shift` + 左键点击 | 将所有物品移到另一侧 |
| `Q` + 左键拖动 | 从拖过的每堆丢弃 1 个 |
| `Shift+Q` + 左键拖动 | 丢弃整堆 |
| `Shift+Q` + 右键拖动 | 丢弃，保留 1 个 |
| `W` / `S` + 左键点击 | 将 1 个移向界面上方 / 下方 |
| `Shift+W` / `Shift+S` + 左键点击 | 将整堆移向上方 / 下方 |
| `Alt+W` / `Alt+S` + 左键点击 | 将所有同种物品移向上方 / 下方 |
| `W` / `S` + 右键点击 | 移向上方 / 下方，保留 1 个 |
| 在物品堆上按 `Ctrl+Shift+Q` | 丢弃所有同种物品 |
| 光标持有物品时 `Shift` + 左键点击界面外 | 丢弃所有与持有物品相同的物品 |
| 光标持有物品时 `Shift` + 点击空槽位 | 放置同种物品 |

### Item Scroller：合成（工作台）

| 按键 | 功能 |
|---|---|
| 按住 `A` 并中键点击结果槽 | 记住网格中的配方 |
| 按住 `A` | 显示已记住的配方 |
| 点击列表中的配方 | 选中并填入网格 |
| `Ctrl+C` | 用选中的配方尽量合成一次 |
| 按住 `Ctrl+Alt+C` | 批量合成并丢出成品 |
| `Ctrl+M` | 将成品移到物品栏（或另一侧） |
| `Ctrl+T` | 将成品丢到地上 |
| 右键点击结果槽 | 合成一组 |
| 在结果槽上滚动滚轮 | 合成并移动 |

### Inventory Profiles Next：整理与移动

| 按键 | 功能 |
|---|---|
| `R` | 整理鼠标所在的物品栏或容器（默认不含快捷栏） |
| `Alt+R` | 连同快捷栏一起整理 |
| 整理按钮（右上） | 按普通、列、行方式整理 |
| 在整理按钮上滚动滚轮 | 更改排序方式 |
| 全部移动按钮 / `R+T` | 将同种物品移到另一侧 |
| `Shift` + 全部移动 | 移动全部物品 |
| `Ctrl` + 全部移动 | 只移动鼠标所指的种类 |
| `CapsLock` + 全部移动 | 只补满另一侧的物品堆 |
| `R+M` | 丢弃同种物品（`Shift`：全部） |

### Inventory Profiles Next：锁定、自动补充与配置档

| 按键 | 功能 |
|---|---|
| `Alt` + 左键点击槽位 | 锁定 / 解锁槽位 |
| 使用工具时按住 `Alt` | 暂时停止工具补充 |
| `Ctrl` + 左键点击槽位（物品栏） | 开关该槽位的自动补充 |
| `Ctrl+R`（HUD） | 开关当前快捷栏槽位的自动补充 |
| `R+P`（物品栏） | 将当前装备保存为配置档 |
| `R+1` 至 `R+0`（HUD） | 应用对应编号的配置档 |
| `R+Z` / `R+X`（HUD） | 下一个 / 上一个配置档 |
| `R+H`（HUD） | 恢复已保存的物品排列 |
| `R+Y` | 重新读取规则、配置档和锁定 |

### Inventory Profiles Next：工作方块与交易

| 按键 | 功能 |
|---|---|
| 连续合成复选框 | 材料减少时按相同布局补充（工作台、切石机） |
| Fast Rename 复选框（铁砧） | 连续命名 |
| 在交易上按 `B` / `L` | 设为全局 / 此村民的收藏 |
| `T` | 执行全局收藏交易 |
| `Shift+T` | 执行此村民的收藏交易 |

### 合成工具（仅工作台）

网格左侧会出现 3 个按钮。**快捷键默认未分配**，请在设置界面中分配。

| 操作 | 功能 |
|---|---|
| 旋转 / `Shift` + 旋转 | 将外圈顺时针 / 逆时针移动一格 |
| 均分 | 在同种物品的槽位间平均分配 |
| `Shift` + 均分 | 只有一种物品时铺满所有槽位 |
| 清空 | 将内容放回物品栏 |
| `Shift` + 清空 | 清空并丢弃放不下的部分 |
| 压缩 / 全部压缩（快捷键） | 为鼠标所指物品摆放 9 个（或 4 个）合成方块的配方 |
| 解压 / 全部解压（快捷键） | 摆放将 1 个方块拆开的配方 |

### 快捷栏收藏

容器界面左上角（安装 JEI 时位于 JEI 面板下方）会出现面板。无需 JEI。

| 操作 | 功能 |
|---|---|
| `+` 按钮或快捷键 `saveHotbar`（默认未分配） | 将当前快捷栏保存为一行 |
| 左键点击行（创造模式） | 即使没有这些物品也会填入快捷栏 |
| 左键点击行（生存模式） | 只换入物品栏中已有的相同物品 |
| 鼠标悬停在行上按 `A` | 删除该行 |

## 设置界面

使用 `R+C` 或 `/invutils gui [itemscroller|ipnext|craftingtools|favorites]` 打开。顶部是模组标签页，左侧是分类，右侧是选项。再次打开时回到上次的标签页，关闭时自动保存。

- 搜索框、章节索引、各选项的 Reset
- 数值选项：滑块，或按 `T` 切换为输入框
- 快捷键：点击按钮，按下按键后全部松开即可分配。`Esc` 清除分配。左侧图标打开高级设置（右键恢复默认）
- 颜色：色块和 `#AARRGGBB` 输入框

## 命令

| 命令 | 说明 |
|---|---|
| `/invutils gui [标签页]` | 打开设置界面 |
| `/invutils config list [分类]` | 列出分类，或分类中的选项和值 |
| `/invutils config get <分类> <名称>` | 显示选项 |
| `/invutils config set <分类> <名称> <值>` | 更改选项（快捷键格式：`LEFT_CONTROL,C`） |
| `/invutils config reset <分类> <名称>` | 恢复选项默认值 |
| `/invutils save` / `reload` | 写入 / 重新读取配置文件 |

## 配置文件

位于 `mods/InventoryUtils/config/`。

| 文件 | 内容 |
|---|---|
| `itemscroller.json` | Item Scroller 设置 |
| `recipes_<世界名>.json` | 已记住的配方 |
| `inventoryprofilesnext/inventoryprofiles.json` | Inventory Profiles Next 设置 |
| `inventoryprofilesnext/rules-v2.*.txt` | 排序规则 |
| `inventoryprofilesnext/<世界名>/lockSlots.txt` | 槽位锁定 |
| `inventoryprofilesnext/<世界名>/profiles-V2.txt` | 配置档 |
| `inventoryprofilesnext/villager-trading-config-v2.json` | 交易收藏 |
| `craftingtools.json` | 合成工具设置（`mode`：`BUTTONS_AND_KEYS` / `KEYS_ONLY` / `DISABLED`，`showButtons`，快捷键） |
| `hotbarfavorites.json` | 快捷栏收藏设置 |
| `hotbar-favorites.json` | 已保存的快捷栏 |
