## Item Scroller

- ホイールで移動: 1 個・スタック・同種すべて・全部
- ドラッグで移動・廃棄（スタックごと・1 個残す・1 個ずつ・同種）
- `W` / `S` で画面の上 / 下の側へ移動
- 同種をすべて捨てる、`Shift` で置く
- レシピをワールドごとに記憶し、一覧からクラフト
- 大量クラフト、できた物の移動・投げ捨て、結果の枠から 1 スタック分クラフト
- クリエイティブでも動く（`enableInCreative`、既定オン。統合版で追加）

## Inventory Profiles Next

- **並べ替え**: 通常・列・行。並び順の方式と規則ファイルを選べる
- **移動**: 全部・同種のみ・マウスの下の種類・補充のみ、同種の廃棄
- **スロットのロック**: 並べ替えと移動の対象外にする。画面とホットバーに鍵の印を出す
- **自動補充**: 尽きたスタックや壊れかけの道具を入れ替える。スロットごとに切り替え可能
- **プロファイル**: 装備とホットバーの並びを保存して切り替える
- **連続クラフト**: 作業台・石切台
- **金床**: Fast Rename
- **村人の取引**: 全体 / 村人ごとのお気に入りをキーで実行

## クラフトツール 相当の機能

公開されている機能の説明から独自に実装しました。作業台のみで動きます。

- 回す・ならす・広げる・クリア・強制クリア
- 9 個 / 4 個のレシピでの圧縮・展開
- グリッドの左のボタン。動作モードは `BUTTONS_AND_KEYS` / `KEYS_ONLY` / `DISABLED`

## ホットバーのお気に入り

- ホットバー全体を保存し、コンテナの画面の欄から呼び出す。JEI は不要
- クリエイティブでは持っていなくても出す
- サバイバルではインベントリにある同じ物だけ入れ替える
- データ入りの品（中身入りのチェストなど）を NBT ごと戻せるのは**ローカルワールドだけ**で、外部サーバでは戻せない

## 設定画面

1 つの画面（`R+C` または `/invutils gui`）に Item Scroller・Inventory Profiles Next・クラフトツール 相当・ホットバーのお気に入りのタブがあります。検索・見出しの索引・スライダー・ホットキーの取り込み・項目ごとの Reset を備えます。

## Java 版との違い

- 重なる機能は統合しています。並べ替えと村人の取引は Inventory Profiles Next、ホイール・ドラッグの移動とクラフト補助は Item Scroller の側です。
- 設定を開くキーは `R+C` の 1 つです。
- Inventory Profiles Next の切り替えキー付きの真偽は、真偽のみです。
- 色は色見本と `#AARRGGBB` の入力欄で編集します（色の小窓はありません）。

## 既知の問題

- クライアント専用です。キーボード・マウスと PC のクラシック UI で使います。
- クリエイティブ一覧に無い NBT 付きの品は、持っていない限り外部サーバでは戻せません。
- マウスを速くドラッグすると、取りこぼすことがあります。
- 自動補充の通知に音はありません。
- すべての機能を外部サーバで確かめてはいません。Realms は未確認です。
