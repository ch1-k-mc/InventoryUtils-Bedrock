## 按鍵

`A+B` 表示按住 `A` 再按 `B`。下表為預設值，所有快捷鍵都可在設定畫面中變更。

### Item Scroller：移動（在容器畫面中）

| 按鍵 | 功能 |
|---|---|
| 在物品堆上滾動滾輪 | 逐個移到另一側（上下決定方向） |
| `Shift` + 滾輪 | 移動整堆 |
| `Alt` + 滾輪 | 移動所有同種物品 |
| `Alt+Shift` + 滾輪 | 移動所有物品 |
| `Shift` + 左鍵拖曳 | 移動拖過的物品堆 |
| `Shift` + 右鍵拖曳 | 移動拖過的物品堆，保留 1 個 |
| `Ctrl` + 左鍵拖曳 | 從拖過的每堆移動 1 個 |
| `Alt` + 左鍵拖曳 | 移動與拖過物品同種的全部物品 |
| `Alt+Shift` + 左鍵點擊 | 將所有物品移到另一側 |
| `Q` + 左鍵拖曳 | 從拖過的每堆丟棄 1 個 |
| `Shift+Q` + 左鍵拖曳 | 丟棄整堆 |
| `Shift+Q` + 右鍵拖曳 | 丟棄，保留 1 個 |
| `W` / `S` + 左鍵點擊 | 將 1 個移向畫面上方 / 下方 |
| `Shift+W` / `Shift+S` + 左鍵點擊 | 將整堆移向上方 / 下方 |
| `Alt+W` / `Alt+S` + 左鍵點擊 | 將所有同種物品移向上方 / 下方 |
| `W` / `S` + 右鍵點擊 | 移向上方 / 下方，保留 1 個 |
| 在物品堆上按 `Ctrl+Shift+Q` | 丟棄所有同種物品 |
| 游標持有物品時 `Shift` + 左鍵點擊畫面外 | 丟棄所有與持有物品相同的物品 |
| 游標持有物品時 `Shift` + 點擊空欄位 | 放置同種物品 |

### Item Scroller：合成（工作台）

| 按鍵 | 功能 |
|---|---|
| 按住 `A` 並中鍵點擊結果欄 | 記住網格中的配方 |
| 按住 `A` | 顯示已記住的配方 |
| 點擊清單中的配方 | 選取並填入網格 |
| `Ctrl+C` | 用選取的配方盡量合成一次 |
| 按住 `Ctrl+Alt+C` | 大量合成並丟出成品 |
| `Ctrl+M` | 將成品移到物品欄（或另一側） |
| `Ctrl+T` | 將成品丟到地上 |
| 右鍵點擊結果欄 | 合成一組 |
| 在結果欄上滾動滾輪 | 合成並移動 |

### Inventory Profiles Next：整理與移動

| 按鍵 | 功能 |
|---|---|
| `R` | 整理滑鼠所在的物品欄或容器（預設不含快捷列） |
| `Alt+R` | 連同快捷列一起整理 |
| 整理按鈕（右上） | 依一般、欄、列方式整理 |
| 在整理按鈕上滾動滾輪 | 變更排序方式 |
| 全部移動按鈕 / `R+T` | 將同種物品移到另一側 |
| `Shift` + 全部移動 | 移動全部物品 |
| `Ctrl` + 全部移動 | 只移動滑鼠所指的種類 |
| `CapsLock` + 全部移動 | 只補滿另一側的物品堆 |
| `R+M` | 丟棄同種物品（`Shift`：全部） |

### Inventory Profiles Next：鎖定、自動補充與設定檔

| 按鍵 | 功能 |
|---|---|
| `Alt` + 左鍵點擊欄位 | 鎖定 / 解鎖欄位 |
| 使用工具時按住 `Alt` | 暫時停止工具補充 |
| `Ctrl` + 左鍵點擊欄位（物品欄） | 開關該欄位的自動補充 |
| `Ctrl+R`（HUD） | 開關目前快捷列欄位的自動補充 |
| `R+P`（物品欄） | 將目前裝備儲存為設定檔 |
| `R+1` 至 `R+0`（HUD） | 套用對應編號的設定檔 |
| `R+Z` / `R+X`（HUD） | 下一個 / 上一個設定檔 |
| `R+H`（HUD） | 還原已儲存的物品排列 |
| `R+Y` | 重新讀取規則、設定檔與鎖定 |

### Inventory Profiles Next：工作方塊與交易

| 按鍵 | 功能 |
|---|---|
| 連續合成核取方塊 | 材料減少時依相同配置補充（工作台、切石機） |
| Fast Rename 核取方塊（鐵砧） | 連續命名 |
| 在交易上按 `B` / `L` | 設為全域 / 此村民的收藏 |
| `T` | 執行全域收藏交易 |
| `Shift+T` | 執行此村民的收藏交易 |

### 合成工具 類功能（僅工作台）

網格左側會出現 3 個按鈕。**快捷鍵預設未指派**，請在設定畫面中指派。

| 操作 | 功能 |
|---|---|
| 旋轉 / `Shift` + 旋轉 | 將外圈順時針 / 逆時針移動一格 |
| 均分 | 在同種物品的欄位間平均分配 |
| `Shift` + 均分 | 只有一種物品時鋪滿所有欄位 |
| 清空 | 將內容放回物品欄 |
| `Shift` + 清空 | 清空並丟棄放不下的部分 |
| 壓縮 / 全部壓縮（快捷鍵） | 為滑鼠所指物品擺放 9 個（或 4 個）合成方塊的配方 |
| 解壓 / 全部解壓（快捷鍵） | 擺放將 1 個方塊拆開的配方 |

### 快捷列收藏

容器畫面左上角（安裝 JEI 時位於 JEI 面板下方）會出現面板。不需要 JEI。

| 操作 | 功能 |
|---|---|
| `+` 按鈕或快捷鍵 `saveHotbar`（預設未指派） | 將目前快捷列儲存為一行 |
| 左鍵點擊行（創造模式） | 即使沒有這些物品也會填入快捷列 |
| 左鍵點擊行（生存模式） | 只換入物品欄中已有的相同物品 |
| 滑鼠停在行上按 `A` | 刪除該行 |

## 設定畫面

使用 `R+C` 或 `/invutils gui [itemscroller|ipnext|craftingtools|favorites]` 開啟。頂部是模組分頁，左側是分類，右側是選項。再次開啟時回到上次的分頁，關閉時自動儲存。

- 搜尋框、章節索引、各選項的 Reset
- 數值選項：滑桿，或按 `T` 切換為輸入框
- 快捷鍵：點擊按鈕，按下按鍵後全部放開即可指派。`Esc` 清除指派。左側圖示開啟進階設定（右鍵還原預設）
- 顏色：色塊與 `#AARRGGBB` 輸入框

## 指令

| 指令 | 說明 |
|---|---|
| `/invutils gui [分頁]` | 開啟設定畫面 |
| `/invutils config list [分類]` | 列出分類，或分類中的選項與值 |
| `/invutils config get <分類> <名稱>` | 顯示選項 |
| `/invutils config set <分類> <名稱> <值>` | 變更選項（快捷鍵格式：`LEFT_CONTROL,C`） |
| `/invutils config reset <分類> <名稱>` | 還原選項預設值 |
| `/invutils save` / `reload` | 寫入 / 重新讀取設定檔 |

## 設定檔

位於 `mods/InventoryUtils/config/`。

| 檔案 | 內容 |
|---|---|
| `itemscroller.json` | Item Scroller 設定 |
| `recipes_<世界名稱>.json` | 已記住的配方 |
| `inventoryprofilesnext/inventoryprofiles.json` | Inventory Profiles Next 設定 |
| `inventoryprofilesnext/rules-v2.*.txt` | 排序規則 |
| `inventoryprofilesnext/<世界名稱>/lockSlots.txt` | 欄位鎖定 |
| `inventoryprofilesnext/<世界名稱>/profiles-V2.txt` | 設定檔 |
| `inventoryprofilesnext/villager-trading-config-v2.json` | 交易收藏 |
| `craftingtools.json` | 合成工具 類功能設定（`mode`：`BUTTONS_AND_KEYS` / `KEYS_ONLY` / `DISABLED`，`showButtons`，快捷鍵） |
| `hotbarfavorites.json` | 快捷列收藏設定 |
| `hotbar-favorites.json` | 已儲存的快捷列 |
